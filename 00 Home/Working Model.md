# Working Model

## Principle

Automation creates drafts.

Humans decide what becomes real knowledge.

## Flow

1. n8n creates or updates a note in `02 Ideas/Short Form/Generated/`
2. the draft is reviewed in Obsidian or GitHub
3. if it is worth keeping, it is rewritten or moved into `Reviewed`
4. the main vault can later absorb the refined version

## Guardrails

- automation should not edit reviewed notes
- automation should not edit manually curated maps or series notes
- generated notes are safe to overwrite
